# 大学祭 当日台本（SCAM DETECTIVE 体験ブース）

会場：**学生ホール**　／　ゲーム：`https://eguchi-kd.github.io/scam-detective/`　／　所要：約10分
目的：**研究に使える参加者（本人初回・同意あり・最後まで完了・参加者コードを記録）をできるだけ多く集める**こと。そのために「足を止めてもらう → 迷わず始めてもらう → 最後まで遊んでもらう → コードを記録する」の各段階で取りこぼしを減らす。

---

## 0. 絶対に守ること（台本より優先）

| # | 守ること | 理由 |
|---|---|---|
| 1 | **遊ぶ前に、見分け方のコツや答えを言わない**（「送信元の番号を見て」「URLを確認して」「日付に注目」などは禁止） | 事前テストの前に知識を与えると、研究の主な評価（ゲームの前後の変化）が正しく測れなくなる |
| 2 | **参加を無理に勧めない**。断られたらすぐ引く。途中でやめたい人は止めない | 倫理審査の条件（参加は自由・いつでもやめられる） |
| 3 | 18歳未満は**保護者の同伴と書面の同意**（確認事項を読んでもらい、署名用紙に署名）がないと研究参加にしない | 倫理審査の条件。ポスターには書いていないので**口頭で必ず確認** |
| 4 | **プレイ中は操作だけ手伝い、内容（詐欺かどうか）は答えない**。手伝ったら記録用紙のメモに書く | 支援の有無は除外の判断に使う |
| 5 | 遊び終えた人に「**まだ遊んでいない人に答えやコツを話さないでね**」とお願いする。待っている人に他の人の画面をのぞかせない | 後から遊ぶ人の事前テストが汚れる |
| 6 | 参加者の氏名を記録用紙に書かない。署名用紙と記録用紙は**別々に保管** | 匿名性の約束 |
| 7 | 参加に使う端末は**テストモードを解除**しておく（タイトルに「🧪 テストモード中」が出ていないこと） | テストモードのままだと研究データにならない |

## 1. 全体の流れ（1人あたり 約12〜15分）

```
[A 呼び込み] 通路・A3ポスター前（10〜30秒）
      ↓
[B 声かけ] ブース前・A1ポスター（30秒〜1分）
      ↓
[C 受付] はじめてか・年齢・同意（1〜2分）
      ↓
[D スタート] 端末の準備 →「はじめて遊ぶ」（30秒）
      ↓
[E プレイ] 同意→属性→事前テスト→練習→本編6問→事後テスト→アンケート（約10分）
      ↓
[F 終了] 参加者コード・送信済みの確認、記録（30秒）
      ↓
[G 振り返り] 答え合わせの補足・お礼・口止めのお願い（1〜2分、任意）
```

### 役割分担（2〜3人いる場合）
| 役割 | 主な場所 | 仕事 |
|---|---|---|
| 呼び込み係 | 通路・入口 | A・B。人を連れてくる。混雑時は待ち時間を伝える |
| 受付係 | 受付机 | C・D・F。同意書・記録用紙を管理。**全員の参加者コードを記録** |
| 見守り係 | プレイ席 | E。操作の困りごとだけ対応。終わった人を受付へ戻す |

1人の時：呼び込みは最小限にし、受付と見守りを優先する（記録の取りこぼしは研究上の損失が大きい）。

### 同時に遊べる人数の目安
- 自分のスマホで遊ぶ人は何人でも並行できる。見守り1人で **4〜5人** まで。
- 貸し出し端末は台数分。終わったら次の人の前に必ずタイトル画面へ戻し「はじめて遊ぶ」から始める（前の人の続きを渡さない）。

## 2. パート別の台本

### A. 呼び込み（通路・A3ポスター前）
狙い：**3秒で足を止め、10秒で「やってみてもいい」と思ってもらう**。説明は短く、問いかけで始める。

**基本の一言（どれか1つ）**
- 「スマホに来た通知、詐欺か見破れますか？ 10分の推理ゲームやってます！」
- 「部屋とスマホを見比べて、詐欺を見破る3Dゲームです。学生ホールでやってます！」
- 「詐欺メッセージ見破りゲーム、挑戦者募集中です！」
- 「あなたは見破れる？ スマホだけで遊べます！」

**相手別**
| 相手 | セリフ例 |
|---|---|
| 中高生のグループ | 「スマホで遊べる推理ゲームあります！ 探偵タイプ診断もできるよ」「何問見破れるか友達と比べてみませんか？（※答えは教え合わないでね）」 |
| 大学生 | 「卒業研究で作った3Dゲームです。10分くらい、協力してもらえると助かります！」 |
| 親子連れ | 「お子さんと一緒にどうですか？ 詐欺の見分け方を体験で学べるゲームです」 |
| 大人・年配の方 | 「最近多いスマホ詐欺を、ゲームで体験できる展示です。よかったら見ていってください」 |
| 立ち止まってポスターを見ている人 | 「気になりました？ 実際に遊べますよ、すぐそこです」 |

**反応への返し**
| 相手の反応 | 返し |
|---|---|
| 「何分？」 | 「10分くらいです。スマホがあればすぐ始められます」 |
| 「難しい？」 | 「最初に操作の練習があるし、ヒントも使えるので大丈夫です」 |
| 「お金かかる？」 | 「かかりません。登録もいりません」 |
| 「あとで行く」 | 「ありがとうございます！ 学生ホールの〇〇あたりです。待ってます」（しつこく追わない） |
| 「いいです」 | 「失礼しました！ よかったら後で見に来てください」（すぐ引く） |

**やってはいけない言い方**：「詐欺は送信元を見ればすぐ分かるんですよ」「簡単だから全問正解できますよ」（コツの漏洩・過度な約束）

---

### B. 声かけ（ブース前・A1ポスター）
狙い：**何をするか・どれくらいかかるか・研究であること**を30秒で伝え、受付へ誘導する。

**30秒版（基本）**
> 「こんにちは！ これは、部屋の中の手がかりとスマホに届いた通知を見比べて、詐欺かどうかを見破る3Dゲームです。
> 卒業研究で作っていて、ゲームの前と後に短いクイズがあって、詐欺を見分ける力が変わるかを調べています。
> 10分くらいで、自分のスマホで遊べます。よかったら参加してみませんか？」

**15秒版（混雑時・急いでいる人）**
> 「詐欺を見破る3Dゲームの研究をしてます。10分くらい、スマホで遊べます。やってみますか？」

**子ども向け**
> 「スマホに届いたメッセージが、ほんものか、にせものかを当てるゲームだよ。お部屋の中を歩いて手がかりを探すんだ。やってみる？」

**「研究って何をするの？」と聞かれたら（1分版）**
> 「ゲームを遊ぶ前と後に、短いクイズを6問ずつ解いてもらいます。その正解数がゲームの前後で変わるかを調べるのが研究の目的です。
> 記録するのはゲームでの答えとかかった時間、最後のアンケートだけで、名前や連絡先は聞きません。最初の画面で説明を読んで、同意してもらえた場合だけ記録します。途中でやめても大丈夫です」

**研究内容を詳しく知りたい人向け（3分版：教員・保護者・研究に関心のある人）**
> 「詐欺のメッセージは本物そっくりで、『今すぐ』と急がせてくるので、注意点を知っていても実際の場面で使えないことが課題です。
> そこで、部屋の中の情報――予定やメモや掲示物――と、スマホに届いた通知を自分で見比べて、食い違いに気づく体験をするゲームを作りました。
> 参加者には、ゲームの前に6問、ゲーム本編で6問、ゲームの後に6問の判断をしてもらいます。前後のクイズの正答数の変化を主な評価にしていて、ほかに、詐欺を見逃す誤りと正常な通知を疑ってしまう誤りの両方、自信の度合いと正解の関係、どこを調べたか、遊びやすさのアンケートも見ています。
> データは匿名で、同意した方の分だけを統計的に分析して、卒業論文にまとめます」

※ 詳しい人に聞かれても、**問題の中身や正解・見分け方は、遊んだ後に**話す（遊ぶ前の人がそばにいる時は特に注意）。

---

### C. 受付
狙い：**本人初回か・年齢・同意**を確認し、記録用紙に記入する準備をする。ここで聞く順番を固定すると取りこぼしが減る。

**① はじめてかどうか**
> 「このゲーム、遊ぶのは今日がはじめてですか？」
- はじめて → 研究参加として進める（②へ）
- 2回目以降・友達の画面を見た → 「では『2回目以降（自由プレイ）』で遊べます。テストなしでゲームだけ楽しめます」（研究データにはしない。記録用紙のメモに「2回目」「他人のプレイを見た」など）

**② 年齢**
> 「失礼ですが、18歳以上ですか？」
- 18歳以上 → ③へ
- 18歳未満で保護者が一緒 → 保護者に：
  > 「研究への参加には保護者の方の同意をお願いしています。こちらの確認事項を読んでいただいて、よろしければこの用紙にご署名をお願いします」
  > 子どもに（アセント）：「名前は記録しないよ。いつやめてもいいからね。こわい・気分が悪いときはすぐ言ってね。やってみる？」
- 18歳未満で保護者がいない → 
  > 「ごめんなさい、このブースで遊んでもらうには保護者の方の同意が必要なんです。保護者の方と一緒にもう一度来てもらえたらうれしいです！ よかったらポスターを見ていってね」
  （自由プレイでも、同意すれば回答は記録されるため、**保護者のいない未成年にはブースでプレイを勧めない**。ポスターの説明を見てもらう程度にとどめる）

**③ 遊び方の確認**
> 「自分のスマホで遊びますか？ こちらの端末も貸し出せます」
- 自分のスマホ → QRを読んでもらう：「カメラでこのQRを読んでください。ブラウザで開きます」
- 貸し出し端末 → 「こちらをどうぞ」（タイトル画面で「はじめて遊ぶ」を押した状態で渡す）

**④ 一言の約束（プレイ前に毎回）**
> 「一人で、相談せずに進めてください。操作で困ったときだけ声をかけてください。最後に出てくる参加者コードを、受付で見せてくださいね」

**グループで来た時**
> 「それぞれ自分のスマホで、同時に始めてください。答えは相談しないで、終わってからみんなで比べてくださいね」
（並んで遊ぶと画面が見えるので、少し離れて座ってもらう）

**署名用紙**：記入済みの欄は**次の人が書く前に厚紙で隠す**。

---

### D. スタート（端末の準備）
- 自分のスマホ：**最初の画面で「はじめて遊ぶ」**を押すよう案内。
  > 「最初の画面で、青い『はじめて遊ぶ』を押してください」
- 「この端末では以前にこのゲームを遊んだ記録があります」と出たら：
  > 「本人が今日はじめてなら『はじめてです』、前に遊んだことがあれば『2回目以降です』を押してください」（家族の端末で起きる）
- **テストモード中の表示が出ていたら研究データにならない**ので、貸し出し端末なら「テストモードを解除」を押してから始める。参加者のスマホで出た場合（以前に試験用URLを開いた端末）も解除を案内。

---

### E. プレイ中（見守り）
狙い：**最後まで遊んでもらう**（途中離脱を減らす）。**内容には答えない**。

**画面ごとの案内（聞かれた時・止まっている時だけ）**
| 画面 | 案内のセリフ |
|---|---|
| 同意画面 | 「説明を読んで、よければチェックを入れて『同意して次へ』を押してください」（同意を急かさない） |
| 属性・事前テスト | 「直感で大丈夫です。分からなくても気にしないで選んでください」 |
| 横向きの案内 | Android：「『↻ 横向きにする』を押してください」／iPhone：「画面の自動回転をオンにして、スマホを横にしてください」 |
| 練習 | 「上の指示に1つずつ従えば進みます。画面をなぞると見回せて、🎯正面で机の方に戻ります。練習は正解がないので気軽にどうぞ」 |
| 本編 | 「部屋の中を歩いて、気になるものを調べてみてください。迷ったら💡ヒントも使えます」 |
| 事後テスト（縦向き） | 「最後のクイズです。スマホを縦に戻してください」（Android は『↻ 縦向きに戻す』） |
| アンケート | 「あと1分くらいです。最後のアンケートに答えると結果発表です！」 |

**聞かれても答えないこと（内容の質問）**
| 質問 | 返し |
|---|---|
| 「これって詐欺？」 | 「それを見破るゲームなので、自分の考えで選んでみてください。答えは最後に分かりますよ」 |
| 「どこを見ればいい？」 | 「部屋の中やスマホを、気になるところから調べてみてください。困ったら💡ヒントを使えます」 |
| 「合ってた？」 | 「答え合わせは最後の結果発表でまとめて出ます。お楽しみに！」 |

**操作の困りごと（答えてよい）**
| 困りごと | 対応 |
|---|---|
| 横にしても画面が回らない | Android：「『↻ 横向きにする』を押してください」／iPhone：コントロールセンターの回転ロックを解除 |
| 動けない・見回せない | 「左の丸いスティックを押したまま動かすと歩けます。画面をなぞると見回せます」 |
| 向きが分からなくなった | 「右の🎯正面を押すと机の方に戻ります」（問題が変わるたびに最初の位置にも戻ります） |
| 見回すのが速すぎる・遅すぎる | 「右の『感度』を押すと 低・中・高 を切り替えられます」 |
| 調べるボタンが押せない | 「近づくとボタンが押しやすくなります」 |
| 「決定する」が見えない | 「下にスクロールの印が出ている時は、下にスクロールできます」 |
| 動画（窓の外）が止まっている | 問題なし（省電力の端末では静止画になる） |

※ 操作を**代わりに操作した・大きく手伝った**場合は、記録用紙のメモに「操作を手伝った」と書く。

**途中でやめたい人**
> 「大丈夫です、ここまでありがとうございました！」（引き止めない。記録用紙のメモに「途中でやめた」）

**気分が悪くなった人（画面酔い）**
> 「すぐやめて大丈夫です。少し休んでください」（座ってもらう。メモに「中断（酔い）」）

**通信が切れて「インターネットに接続していない」画面になった**
1. 「通信が戻るまで少し待ってください」
2. **再読み込みはしない**。同じタブのアドレス欄に `https://eguchi-kd.github.io/scam-detective/game/`（結果まで終わっていたら `/result/`）を入れて開く
3. **タイトル画面から「はじめて遊ぶ」は押さない**（回答が消える）
（詳しくは公開前チェックリストの「通信が切れて画面が移れなかった時の対処」）

---

### F. 終了（記録）
狙い：**全員の参加者コードを、送信済みを確認してから記録**する。

> 「おつかれさまでした！ 最後の画面の下にある参加者コードを見せてもらえますか？ 『データ送信済み』になっているかも確認させてください」

**記録用紙（参加者コード記録用紙）に書くこと**
- 時刻・参加者コード（英数字6文字。0とO、1とIははっきり）
- はじめて？：はい／いいえ
- 送信済み：☐にチェック
- メモ：手伝った・中断・交代・18歳未満で同意書あり・2回目・他人のプレイを見た など

**「送信待ち」のままの時**
> 「通信が戻ると自動で送られます。少し待ってもらえますか？」（Wi-Fiやモバイル通信を確認。結果画面の「再送する」を押す。**「もう一度プレイ」は押さない**＝回答が消える）

---

### G. 振り返り・お礼（任意・1〜2分）
狙い：**満足してもらい、口コミで次の参加者を呼ぶ**。ただし**答えは口止め**する。

**お礼**
> 「ご協力ありがとうございました！ 研究に使わせていただきます」

**答え合わせの補足（結果画面を見ながら）**
- 遊び終えた人には、見分け方の話をしてよい（解説・結果画面の内容に沿って）。
  > 「どの問題が難しかったですか？ 解説にもあったように、部屋の情報と通知を見比べるのがポイントなんです」
- **周りに遊ぶ前の人がいる時は小声で、または離れた場所で**。

**口止めのお願い（毎回）**
> 「これから遊ぶ友達には、答えやコツは内緒にしてもらえますか？ 研究のデータが変わってしまうので…。代わりに『おもしろかったよ』って誘ってもらえるとうれしいです！」

**口コミのお願い**
> 「よかったら友達にも、学生ホールでやってるよって伝えてください。何問見破れたか比べると盛り上がります（答えは内緒で）」

**探偵タイプ診断について聞かれたら**
> 「本編6問の答え方から簡単に判定したお楽しみの診断です。性格や能力を正確に表すものではないので、気軽に見てください」（未成年には特にこの一言を添える）

## 3. よくある質問（Q&A）

| 質問 | 答え |
|---|---|
| 個人情報は大丈夫？ | 「ゲームでの回答は匿名で記録します。名前や連絡先は聞きません。保護者の方の署名用紙はゲームの回答とは結び付けずに保管します」 |
| データは消せる？ | 「名前なしで記録しているので、送信した後に特定の方のデータだけを消すことはできません。そのため最初の画面で同意をお願いしています」 |
| 出てくる詐欺は本物？ | 「学習用に作った模擬例です」 |
| 何に使うの？ | 「統計的に分析して卒業論文にまとめます。公表する時も個人が特定されることはありません」 |
| 家で遊べる？ | 「同じURLで遊べます。ただ研究への参加は、ここで受付をしてからお願いしています」 |
| 友達と一緒にやっていい？ | 「それぞれのスマホで、相談せずにお願いします。終わったら比べてください」 |
| 前に遊んだことがある | 「『2回目以降（自由プレイ）』で遊べます」 |
| スマホを持っていない | 貸し出し端末を案内（なければ「ごめんなさい、今は端末が埋まっていて…〇分ほどで空きます」） |
| 時間がない | 「10分くらいかかるので、時間がある時にまたどうぞ」（無理に始めない。途中離脱は研究に使えない） |

## 4. 混雑・トラブル時

| 状況 | 対応・セリフ |
|---|---|
| 待ちが出た | 「今〇人遊んでいて、あと5分くらいで端末が空きます。自分のスマホならすぐ始められます」 |
| 待っている人が他人の画面を見ている | 「始まるまで、こちらのポスターを見ていてもらえますか」（画面をのぞかせない。見てしまった人はメモに記録） |
| QRが読めない | アドレスを伝える：「eguchi-kd.github.io の scam-detective です」（紙に書いて見せる） |
| 画面が真っ黒・進まない | 一度ブラウザを閉じずに数秒待つ → だめなら貸し出し端末に切り替え（最初から。メモに「端末トラブルでやり直し」） |
| 発熱・動作が重い | 「少し休んでも大丈夫です」（端末が熱い時は無理をさせない） |
| 書き込みが異常に多い・知らない時間帯に増えている（監視） | 公開前チェックリスト3の緊急停止の手順 |

## 6. 取りこぼしを減らすコツ（まとめ）
1. **最初の一言は問いかけ**（「見破れますか？」）。説明は短く、詳しい話は聞かれてから。
2. **自分のスマホで並行して遊んでもらう**（待ち時間をなくす）。貸し出し端末は持っていない人向け。
3. **受付の質問の順番を固定**（はじめて？→18歳以上？→スマホ？）して、同意と初回確認の漏れを防ぐ。
4. **プレイ中は声をかけすぎない**が、止まっている人には操作だけ助ける（途中離脱を防ぐ）。
5. **終わった人を必ず受付に戻す**（コードの記録漏れは研究に使えないデータになる）。
6. **口コミをお願いし、答えは口止め**（次の参加者を増やしつつ、データを守る）。
