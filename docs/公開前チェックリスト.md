## 3. 公開範囲と書き込みの監視（A5）
現状：sessions への書き込みは認証なし（読み取りは禁止）。学祭の管理下での利用を前提に受け入れている（分析計画の限界に記載）。締切前にルールの大きな変更（認証の追加など）は入れない。

- **監視**：公開中は1日1回以上、Firebase コンソール → Firestore → 使用量 で書き込み数を確認する。参加者数に比べて書き込みが極端に多い・知らない時間帯に増えている、などは異常の兆候
- **緊急停止**：異常があれば、すべての読み書きを止めるルールに切り替える
  ```
  firebase deploy --only firestore:rules --config firebase.lockdown.json
  ```
  ゲームは動き続けるが、ログは保存されない。原因を確認したら通常のルールに戻す：
  ```
  firebase deploy --only firestore:rules
  ```
- **不特定多数へ広く告知する場合**は前提が変わるので、研究対象を担当者が確認した参加者に限ることを原則とする
